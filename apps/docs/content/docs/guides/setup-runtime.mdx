## Create the mesh manager

<Tabs items={["Web", "React Native", "Node"]}>
  <Tab value="Web">
    ```ts
    import { MeshNetworkManager, createMesh } from "@blemeshjs/sdk-web";

    const mesh = await createMesh(MeshNetworkManager.instance);
    ```
  </Tab>
  <Tab value="React Native">Coming soon!</Tab>
