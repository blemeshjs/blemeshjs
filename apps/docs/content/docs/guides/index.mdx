Use these guides when you already understand the basics and want to get real work done.

If you want one compact proof-of-concept before following full guides, start with [Demo](/docs/demo).

## Start here

1. [Setup Runtime](/docs/guides/setup-runtime) to initialize a usable mesh manager.
2. [Provision a New Device](/docs/guides/provisioning) to bring a device into your network.
3. [Control Device](/docs/guides/control-device) to send model commands to provisioned nodes.

## Which guide should I read?

| I need to... | Go to... |
| --- | --- |
| Verify my app can initialize BLE Mesh | [Setup Runtime](/docs/guides/setup-runtime) |
| Onboard a brand-new device | [Provision a New Device](/docs/guides/provisioning) |
| Send a command to a device that is already provisioned | [Control Device](/docs/guides/control-device) |

<Callout title="At this point, you should have a clear path">
  Pick one guide, complete it end-to-end, then move to the next guide in sequence.
</Callout>
