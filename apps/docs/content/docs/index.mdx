## What BLEMeshJS is for

BLEMeshJS is aimed at teams that need to work with Bluetooth Mesh devices without rebuilding provisioning, transport setup, and model control from scratch.

That usually means one of these product shapes:

- a Web tool for diagnostics, demos, or technician workflows.
- a React Native app that will eventually need mobile-native transport,
- a Node.js service or gateway that manages mesh state over time.
