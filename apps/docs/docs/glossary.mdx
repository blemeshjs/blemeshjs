Use this glossary when Bluetooth Mesh terms show up faster than you can absorb them.

## A

**Address**

The destination used for publish and subscribe traffic. It can point to one element, a group, or a virtual target.

## E

**Element**

A functional part of a node. One physical device can expose multiple elements.

## M

**Model**

The behavior contract attached to an element. Models define what commands or state a device supports.

**Mesh client**

The object returned by `createMesh()`. It scans, connects, and manages sessions.

## N

**Node**

One physical mesh device, such as a light, switch, sensor, or gateway-connected target.

## P

**Provisioning**

The secure onboarding process that adds a new device to the mesh network.

**Publish**

Sending a model message to an address.

## S

**Scene**

A saved multi-device state that can be recalled later.

**Subscribe**

Listening for model messages sent to an address.

**Simulator**

A hardware-free runtime created with `createSimulatorMesh()` for demos, testing, and UI development.
