## Create a mesh client

<Tabs defaultValue="react-native">
  <Tab value="react-native" label="React Native">

```ts
import { createMesh } from "@mesh-link-js/sdk"

const mesh = await createMesh({ platform: "react-native" })
```

  </Tab>
  <Tab value="node" label="Node.js">

```ts
import { createMesh } from "@mesh-link-js/sdk"

const mesh = await createMesh({
  platform: "node",
  transport: { adapter: "usb-dongle" },
})
```

  </Tab>
  <Tab value="web" label="Web">

```ts
import { createMesh } from "@mesh-link-js/sdk"

const mesh = await createMesh({ platform: "web" })
```

## Scan for devices

```ts
const devices = await mesh.scan({ timeout: 10_000 })

if (devices.length === 0) {
  throw new Error("No mesh devices found")
}
```

You should get back a list of discovered devices with identifiers such as `uuid`, `name`, `rssi`, and provisioning status.

## Connect and provision

```ts
const device = await mesh.connect(devices[0].uuid)

await device.provision({
  appKey: "home-app",
  networkKey: "default-network",
})
```

If the device is already provisioned, `device.provision()` is usually a no-op and the SDK continues with the active session.

## Turn the light on

```ts
await device.light.on()
```

To switch it back off:

```ts
await device.light.off()
```

## Full quick start

```ts
import { createMesh } from "@mesh-link-js/sdk"

async function quickStart() {
  const mesh = await createMesh()
  const devices = await mesh.scan({ timeout: 10_000 })
  const device = await mesh.connect(devices[0].uuid)

  await device.provision({ appKey: "home-app" })
  await device.light.on()

  return device
}

await quickStart()
```
