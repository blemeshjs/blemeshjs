Scenes save a known state for several devices so you can recall it later with one action.

## 1. Choose devices

```ts
const ceiling = await mesh.connect("ceiling-light")
const desk = await mesh.connect("desk-light")
const shelf = await mesh.connect("shelf-light")
```

Set the state you want to capture first.

```ts
await ceiling.light.setLevel(80)
await desk.light.setLevel(40)
await shelf.light.off()
```

## 2. Capture the scene

```ts
const evening = await mesh.scenes.create({
  id: 1,
  name: "Evening",
})

await evening.capture([ceiling, desk, shelf])
```

## 3. Recall the scene

```ts
await evening.recall()
```

## Expected behavior

- each device returns to the captured state,
- you avoid sending several manual commands every time,
- scene IDs become stable automation targets across apps and services.

## Full example

```ts
const evening = await mesh.scenes.create({ id: 1, name: "Evening" })

await evening.capture([
  await mesh.connect("ceiling-light"),
  await mesh.connect("desk-light"),
  await mesh.connect("shelf-light"),
])

await evening.recall()
```
