## Pick the next workflow

- Start with [Turn a Light On Or Off](/docs/guides/light-on-off) if you need the smallest useful control path.
- Read [Provision a New Device](/docs/guides/provisioning) if your app brings new hardware online.
- Move to [Control Multiple Devices](/docs/guides/groups) and [Create a Scene](/docs/guides/scenes) once one-device control stops scaling.
- Use [Retry Failed Provisioning](/docs/guides/retry-provisioning) and [Listen to State Updates](/docs/guides/state-updates) for production hardening.
