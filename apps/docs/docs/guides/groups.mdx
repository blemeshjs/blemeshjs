Groups let you address many devices with one publish instead of looping one device at a time.

## 1. Create a group

```ts
const livingRoom = await mesh.groups.create({
  name: "Living Room",
  address: "c000",
})
```

Pick stable group names and addresses that match how operators think about the space.

## 2. Add devices

```ts
await livingRoom.add(await mesh.connect("lamp-1"))
await livingRoom.add(await mesh.connect("lamp-2"))
await livingRoom.add(await mesh.connect("lamp-3"))
```

In production, use real UUIDs or persisted device IDs instead of display names.

## 3. Publish a command

```ts
await livingRoom.light.on()
```

You can also dim the whole group:

```ts
await livingRoom.light.setLevel(60)
```

## Expected behavior

- every subscribed device in the group receives the same publish,
- late devices do not block the rest of the room,
- your app can still inspect each member individually when needed.

## Full example

```ts
const mesh = await createMesh()
const livingRoom = await mesh.groups.create({ name: "Living Room", address: "c000" })

for (const uuid of ["lamp-1", "lamp-2", "lamp-3"]) {
  const device = await mesh.connect(uuid)
  await livingRoom.add(device)
}

await livingRoom.light.on()
```
