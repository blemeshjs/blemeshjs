Use React Native when your app owns the BLE session directly on iOS and Android.

## Install

```bash
yarn add @mesh-link-js/sdk @mesh-link-js/sdk-react-native
```

## Permissions

You need Bluetooth permissions before scanning or connecting.

On iOS, add the Bluetooth usage descriptions your app store review expects.

On Android, request the Bluetooth and nearby-device permissions required by the OS version you support.

<Callout tone="warn">
  If scanning silently returns no devices, check permissions first. On mobile, permission issues often look like empty discovery results rather than explicit BLE errors.
</Callout>

## BLE setup

Initialize the native BLE layer before calling `scan()`.

```ts
import { createMesh } from "@mesh-link-js/sdk"

const mesh = await createMesh({
  platform: "react-native",
  storage: { driver: "async-storage" },
})
```

Recommended defaults:

- keep one mesh client per app session,
- restore persisted keys on startup,
- stop scanning when the screen is backgrounded,
- reconnect only to devices the user is actively interacting with.

## Create the client

```ts
const mesh = await createMesh({ platform: "react-native" })

await mesh.scan({ timeout: 10_000 })
```

## Example screen flow

```ts
const mesh = await createMesh({ platform: "react-native" })
const devices = await mesh.scan({ timeout: 10_000 })
const device = await mesh.connect(devices[0].uuid)

await device.provision({ appKey: "home-app" })
await device.light.on()
```
