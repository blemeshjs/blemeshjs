Provisioning is the moment a device becomes part of your network instead of just a nearby BLE target.

## 1. Create a mesh client

```ts
import { createMesh } from "@mesh-link-js/sdk"

const mesh = await createMesh()
```

## 2. Scan for unprovisioned devices

```ts
const devices = await mesh.scan({
  mode: "unprovisioned",
  timeout: 15_000,
})

const candidate = devices[0]
```

Expected behavior:

- the device appears with a UUID,
- the SDK marks it as unprovisioned,
- you can show the device name or RSSI in your UI.

## 3. Connect and identify

```ts
const device = await mesh.connect(candidate.uuid)

await device.identify({ attention: 5 })
```

Use identify when you need the user to confirm which physical device is about to join the network.

## 4. Provision

```ts
await device.provision({
  appKey: "home-app",
  networkKey: "default-network",
  name: "Desk Lamp",
})
```

After provisioning, persist the network state before leaving the screen or ending the process.

```ts
await mesh.save()
```

## Expected behavior

```txt
found unprovisioned device: Desk Lamp
connected to device
identify started for 5s
provisioning complete
saved mesh state
```

## Full example

```ts
const mesh = await createMesh()
const devices = await mesh.scan({ mode: "unprovisioned", timeout: 15_000 })
const device = await mesh.connect(devices[0].uuid)

await device.identify({ attention: 5 })
await device.provision({ appKey: "home-app", name: "Desk Lamp" })
await mesh.save()
```

## What to do if it fails

1. Disconnect cleanly.
2. Clear any incomplete local provisioning state.
3. Retry with backoff.

Use [Retry Failed Provisioning](/docs/guides/retry-provisioning) for the recovery flow.
