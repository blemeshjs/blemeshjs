This package is where the cross-cutting types live. It is easy to overlook, but most public APIs depend on it.

## Why this package matters

The SDK uses `@mesh-link-js/utils` for identifiers, storage, buffer types, typed event emitters, transport enums, and shared numeric helpers.

## Storage

| Export | Purpose |
| --- | --- |
| `Storage<Value>` | Abstract base class defining `load`, `save`, `get`, `set`, `remove`, and `clear` |
| `BrowserStorage` | Browser implementation that stores data under a namespace in localStorage |

## Identifiers and mesh value types

Common imports include `UUID`, `Address`, `KeyIndex`, `Data`, `ClosedRange`, and numeric aliases used throughout the core and platform packages.

## Events and transport helpers

| Export | Purpose |
| --- | --- |
| `BindableTinyEmitter` | Typed event emitter used by `RNMeshNetworkManager`, `RNProvisioningManager`, and other runtime objects |
| `transport` types | Shared transport constants and helper types used at the bearer layer |

## Typical imports

The most common imports from this package in the repository today are:

- `SigModelId`
- `Address`
- `UUID`
- `Storage`
- `BindableTinyEmitter`
