The mesh client is your entrypoint for discovery and connections.

## createMesh

<ApiSignature
  name="createMesh"
  signature={'createMesh(options?: MeshOptions): Promise<MeshClient>'}
  returns="A ready-to-use mesh client for the active platform"
>
  <p>Create one client for the current runtime. Pass platform or transport options only when the defaults are not enough.</p>

```ts
const mesh = await createMesh({ platform: "react-native" })
```

</ApiSignature>

## mesh.scan

<ApiSignature
  name="mesh.scan"
  signature={'mesh.scan(options?: { timeout?: number; mode?: "mesh" | "unprovisioned" }): Promise<Array<{ uuid: string; name?: string }>>'}
  returns="A list of discovered devices"
>
  <p>Scan for nearby devices. Use `mode: "unprovisioned"` when onboarding new hardware.</p>

```ts
const devices = await mesh.scan({ timeout: 10_000 })
```

</ApiSignature>

## mesh.connect

<ApiSignature
  name="mesh.connect"
  signature={'mesh.connect(uuid: string): Promise<Device>'}
  returns="A connected device handle"
>
  <p>Connect to one device by UUID. The returned device object exposes provisioning helpers, model access, and convenience controls.</p>

```ts
const device = await mesh.connect(devices[0].uuid)
```

</ApiSignature>

## Example

```ts
const mesh = await createMesh()
const devices = await mesh.scan({ timeout: 10_000 })
const device = await mesh.connect(devices[0].uuid)
```
