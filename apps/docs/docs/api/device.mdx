The device object represents one connected node.

## device.provision

<ApiSignature
  name="device.provision"
  signature={'device.provision(options?: { appKey?: string; networkKey?: string; name?: string }): Promise<void>'}
  returns="Nothing"
>
  <p>Provision the device into the current network. Call this when the device is new or not yet trusted by your mesh.</p>

```ts
await device.provision({ appKey: "home-app", name: "Desk Lamp" })
```

</ApiSignature>

## device.disconnect

<ApiSignature
  name="device.disconnect"
  signature={'device.disconnect(): Promise<void>'}
  returns="Nothing"
>
  <p>Close the active session cleanly. Use this before retries, app background transitions, or shutdown.</p>

```ts
await device.disconnect()
```

</ApiSignature>

## device.light

<ApiSignature
  name="device.light"
  signature={'device.light: { on(): Promise<void>; off(): Promise<void>; setLevel(level: number): Promise<void>; onStateChange(listener: (state: LightState) => void): () => void }'}
  returns="A high-level light helper"
>
  <p>Use this convenience surface when you want fast results without working through lower-level model plumbing.</p>

```ts
await device.light.on()
await device.light.setLevel(70)
```

</ApiSignature>

## Example

```ts
const device = await mesh.connect(uuid)

await device.provision({ appKey: "home-app" })
await device.light.on()

const stop = device.light.onStateChange((state) => {
  console.log(state)
})

stop()
```
